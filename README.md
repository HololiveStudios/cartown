# Car Town — Projeto Completo

Este repositório contém a documentação, o frontend (React + Vite + TypeScript + Tailwind + Phaser 3) e o backend (Node.js) do jogo Car Town.

## Estrutura
- `/docs`: Documentação técnica (.md) com a pesquisa de funcionalidades, arquitetura de camadas 2D, balanceamento e especificação backend.
- `/frontend`: Aplicação Web completa em React + Vite + TypeScript + Tailwind CSS + Phaser 3.
- `/backend`: Servidor HTTP REST API e WebSockets em Node.js puro com banco de dados JSON.

## Como Executar

### Backend
1. Entre na pasta `backend`: `cd backend`
2. Execute o servidor: `node server.js`

### Frontend
1. Entre na pasta `frontend`: `cd frontend`
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `npm run dev`
4. Abra a URL exibida no terminal (ex: `http://localhost:5173`)
